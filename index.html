Panduan Instalasi ExamBrowser

1. Cara Instal di Laptop (Google Chrome / Microsoft Edge)

  1. Buka tautan ExamBrowser menggunakan browser Chrome atau Edge.
  2. Klik tombol "Instal Aplikasi" di header kanan atas, atau klik ikon Install di ujung kanan bilah alamat URL.
  3. Konfirmasi Install agar pintasan ExamBrowser terpasang di Desktop / Start Menu Laptop.

2. Cara Instal di Tablet Android / iPad

  1. Tablet Android (Chrome): Ketuk ikon menu titik tiga (⋮) di pojok kanan atas → pilih Instal Aplikasi atau Tambahkan ke Layar Utama.
  2. iPad (Safari): Ketuk ikon Bagikan (Share) → pilih Tambahkan ke Layar Utama (Add to Home Screen).
